# Plano: Sistema de Idiomas (PT/EN/ES)

## Objetivo
Adicionar um seletor de idioma no painel Settings que permite alternar entre Portugues, Ingles e Espanhol. Todas as strings visiveis do painel serao traduzidas.

## Arquiterura

### 1. Criar tabela de traducoes em `core/init.lua`

Adicionar `GH.Locales` com 3 tabelas (`pt`, `en`, `es`) e uma funcao `GH.T(key)` que retorna a string no idioma atual. A tabela cobre:

- **Settings tab**: titulos das secoes, toggles, sliders
- **Toggle buttons**: textos e descricoes de todos os 58 botoes dos modulos
- **Toasts**: mensagens de ativado/desativado, carregado, erros, etc.
- **Dropdown titles**: "Selecionar Player", "Nome da Parte", etc.
- **ESP tags**: [INIMIGO]/[ENEMY]/[ENEMIGO], etc.
- **Section titles**: "Configuracoes", "Coordenadas"
- **Dynamic strings**: "Posicao salva!", "TP para...", etc.
- **Loader** (`loader.lua`): textos do loading screen

### 2. Adicionar setting `Language` em `GH.Settings`

```lua
GH.Settings = {
    Language = "pt",  -- novo
    -- ... resto existente
}
```

### 3. Adicionar dropdown de idioma na Settings Tab

No `core/init.lua`, antes dos outros settings, adicionar:
```lua
SettingsSection:AddDropdown("Language", {
    Title = GH.T("settings_language"),
    Values = {"Portugues", "English", "Espanol"},
    Default = "Portugues",
    Callback = function(value)
        GH.Settings.Language = mapping[value]  -- "pt"/"en"/"es"
    end,
})
```

**Nota**: O Fluent nao suporta atualizar UI em tempo real. Ao trocar idioma, o usuario precisara re-executar o script para ver as mudancas (ou recarregar). Isso e aceitavel para esse tipo de feature.

### 4. Substituir strings hardcoded

Em todos os arquivos, substituir strings literais por `GH.T("chave")`:

| Arquivo | Qtd strings | Exemplos |
|---------|-------------|----------|
| `core/init.lua` | ~20 | "Configuracoes", "Mostrar Distancia", toasts |
| `modules/combat.lua` | ~15 | descricoes dos toggles, ESP tags, toasts |
| `modules/movement.lua` | ~25 | descricoes, dropdown titles, toasts |
| `modules/visual.lua` | ~8 | descricoes, toast FOV |
| `modules/utility.lua` | ~25 | descricoes, section titles, botoes, toasts |
| `modules/troll.lua` | ~8 | descricoes, dropdown title, toasts |
| `loader.lua` | ~6 | status texts do loading screen |

### 5. Mapeamento de chaves

Chaves padronizadas em snake_case:
- `settings_config` -> "Configuracoes" / "Settings" / "Configuracion"
- `toggle_activate` -> "Ativar" / "Enable" / "Activar"
- `toast_activated` -> "Ativado!" / "Enabled!" / "Activado!"
- `toast_deactivated` -> "Desativado!" / "Disabled!" / "Desactivado!"
- `player_select` -> "Selecionar Player" / "Select Player" / "Seleccionar Jugador"
- etc.

## Notas

- O loader roda antes do core, entao para o loader as traducoes serao hardcoded com um check simples de idioma (ou mantidas em PT como fallback ja que e a tela de loading)
- O SaveManager ja salva carrega as configuracoes, entao o idioma sera persistido automaticamente
- A funcao `GH.T()` sera simples: `return GH.Locales[GH.Settings.Language][key] or GH.Locales["pt"][key] or key`
