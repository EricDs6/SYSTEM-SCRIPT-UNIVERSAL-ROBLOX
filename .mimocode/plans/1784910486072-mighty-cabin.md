# Plano: Migração completa da UI para Fluent Library

## Visão Geral
Reescrever toda a interface do script usando a biblioteca Fluent (dawid-scripts/Fluent), eliminando toda a UI manual criada em `core/init.lua` e os painéis secundários nos módulos.

## O que a Fluent fornece nativamente
- Window com tabs (sidebar + containers)
- Toggle, Slider, Dropdown, Button, Input, Keybind, Colorpicker, Paragraph, Section
- Notificações (`Fluent:Notify`)
- Sistema de save/load de configs (`SaveManager` addon)
- Gerenciador de interface (`InterfaceManager` addon)
- Temas (Dark, etc.) e efeito Acrylic/blur
- Sistema de Dialog
- Minimize keybind

## O que precisa de tratamento especial
- **Painéis secundários** (listas de players): NÃO existem na Fluent. Solução: usar `Dropdown` com lista de jogadores que atualiza automaticamente
- **Crosshair**: UI overlay que não faz parte do painel, continua sendo ScreenGui separada
- **ESP/Highlights/SelectionBoxes**: São 3D, não UI do painel, não mudam

**Nova estrutura de `GH.Initialize()`:**
```lua
function GH.Initialize()
    -- 1. Carregar Fluent
    local Fluent = loadstring(game:HttpGet("https://github.com/dawid-scripts/Fluent/releases/latest/download/main.lua"))()
    local SaveManager = loadstring(game:HttpGet("https://raw.githubusercontent.com/dawid-scripts/Fluent/master/Addons/SaveManager.lua"))()
    local InterfaceManager = loadstring(game:HttpGet("https://raw.githubusercontent.com/dawid-scripts/Fluent/master/Addons/InterfaceManager.lua"))()
    GH.Fluent = Fluent

    -- 2. Criar Window
    local Window = Fluent:CreateWindow({
        Title = "SYSTEM SCRIPT",
        SubTitle = "v2.0",
        TabWidth = 160,
        Size = UDim2.fromOffset(580, 460),
        Theme = "Dark",
    })
    GH.Window = Window

    -- 3. Criar Tabs (baseado nas categorias)
    local Tabs = {}
    for _, cat in ipairs(GH.Categories) do
        Tabs[cat.Name] = Window:AddTab({ Title = cat.Name, Icon = cat.Icon })
    end
    local SettingsTab = Window:AddTab({ Title = "Settings", Icon = "settings" })
    GH.Tabs = Tabs

    -- 4. Processar toggles pendentes
    for _, pending in ipairs(GH.PendingButtons) do
        GH.States[pending.name] = false
        local tab = Tabs[pending.category] or Tabs["Combat"]
        local toggle = tab:AddToggle(pending.name, {
            Title = pending.text,
            Description = pending.description or "",
            Default = false,
        })
        toggle:OnChanged(function()
            GH.States[pending.name] = toggle.Value
            pending.callback(toggle.Value, toggle)
        end)
        GH.Buttons[pending.name] = toggle
        GH.Callbacks[pending.name] = pending.callback
    end

    -- 5. Configurar Settings com Fluent
    -- Debug toggles, sliders, etc. usando tab:AddToggle/AddSlider

    -- 6. Configurar SaveManager
    SaveManager:SetLibrary(Fluent)
    InterfaceManager:SetLibrary(Fluent)
    SaveManager:IgnoreThemeSettings()
    SaveManager:SetFolder("SystemScript")
    InterfaceManager:SetFolder("SystemScript")
    InterfaceManager:BuildInterfaceSection(SettingsTab)
    SaveManager:BuildConfigSection(SettingsTab)

    -- 7. Restaurar config salva
    -- Usar SaveManager:LoadAutoloadConfig()

    -- 8. InputManager global connections
    -- 9. Master loops (Render, Heartbeat, PreSim)
    -- 10. Namecall hook
    -- 11. CharacterAdded handler
    -- 12. PlayerRemoving handler
end
```

**Padrão de adaptação (ex: TeleportPlayer):**
```lua
-- ANTES: Criava ScreenGui manual com lista de players
-- DEPOIS: Usa Dropdown do Fluent que auto-atualiza

local PlayerDropdown = nil
local function refreshPlayerList()
    local playerNames = {}
    for _, p in ipairs(Players:GetPlayers()) do
        if p ~= LocalPlayer then
            table.insert(playerNames, p.Name)
        end
    end
    if PlayerDropdown then
        PlayerDropdown:SetValues(playerNames)
    end
end

function Cheats_ToggleTeleportPlayer(state)
    if not state then
        if PlayerDropdown then PlayerDropdown:Destroy(); PlayerDropdown = nil end
        return
    end
    -- Criar dropdown na tab Movement
    PlayerDropdown = GH.Tabs["Movement"]:AddDropdown("TPPlayer_Select", {
        Title = "Selecionar Player para TP",
        Values = {},
        AllowNull = true,
    })
    PlayerDropdown:OnChanged(function(name)
        if name then
            local player = Players:FindFirstChild(name)
            local targetHrp = player and player.Character and player.Character:FindFirstChild("HumanoidRootPart")
            local myHrp = LocalPlayer.Character and LocalPlayer.Character:FindFirstChild("HumanoidRootPart")
            if targetHrp and myHrp then
                GH.TweenTeleport(myHrp, targetHrp.CFrame + Vector3.new(0, 3, 2))
            end
        end
    end)
    refreshPlayerList()
    -- Atualizar lista quando players entram/saem
end
```

**Decisão confirmada pelo usuário:** Usar Dropdown do Fluent para TODOS os painéis secundários. Elimina toda ScreenGui manual dos módulos.
